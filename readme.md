# 📚 Book Recommender System

This project is a semantic book recommendation system that combines **natural language processing**, **vector search**, and **zero-shot classification** to provide personalized book suggestions based on content, emotion, and genre.

## Project Highlights

-  **Data Preprocessing**  
  Performed exploratory data analysis and data cleaning using **Pandas** to prepare the dataset for downstream tasks.

-  **Semantic Search with Vector Embeddings**  
  Built a **vector database** using **LangChain** and **Hugging Face** embeddings to enable context-aware, similarity-based recommendations.

-  **Genre Classification**  
  Integrated a **zero-shot classifier** from Hugging Face to categorize books by genre, achieving **77% accuracy** without task-specific training.

-  **Emotion-Based Filtering**  
  Employed a **fine-tuned model** to detect emotional tone in book descriptions, further refining recommendation relevance.

-  **User Interface**  
  Developed a simple and intuitive UI using **Gradio**, allowing users to input queries and receive personalized book suggestions.

##  Tech Stack

- Python
- Pandas
- LangChain
- Hugging Face Transformers
- Gradio

##  Features

- Search books semantically using a text prompt
- Filter recommendations by genre or emotional tone
- Easy-to-use interface for real-time interaction
